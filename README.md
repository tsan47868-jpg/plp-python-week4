# Week 4 Assignment: Grades, Eligibility & Smart Decisions

This repository contains the three Python programs for the Week 4 lab assignment.

- `grade_classifier.py` asks for a score between 0 and 100, validates it, and assigns a grade from A to F.
- `eligibility_checker.py` determines whether a person meets the club membership rules using age and consent checks.
- `atm_menu.py` simulates a simple ATM flow with PIN validation and balance checks.

`elif` is better than several separate `if` statements when you want one clear decision path. It lets Python check each condition in order and stop as soon as it finds the matching condition, which makes the logic easier to read and avoids unnecessary comparisons.
